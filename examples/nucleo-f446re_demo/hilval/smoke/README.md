# hilval smoke on a NUCLEO-F446RE

Generated by the hil-validations bench gate for one bench run; do not edit.

Four bare-metal smoke images that check the bench path and the board's own measurement paths, with nothing wired to the headers: `basic` (identity, a 100-line pattern the test recomputes, an independent-watchdog reset with the port open), `echo` (bytes from the bench received as 8N1, 7E1, 7O1 and 8E1), `afin` (timer capture of a pin the CPU drives, GPIO sampling by DMA at 1, 2 and 4 MHz, TIM1 CH1/CH1N in four enable states, USART1 CTS flow control, TIM5 capture of TIM3's trigger across the counter wrap) and `analog` (DAC outputs read back by ADC1 on the same pins). They test no upstream project; later validation images build on what they measure.

Run by [Agentic Hardware-in-the-Loop (Agentic HIL)](https://github.com/agentic-hil/agentic-hil): its test reactor flashes each image, resets the board with the serial port open and records what the image prints; `agentic-hil run-evidence` turns each run into a report a reader without the board can check.

Each image prints lines `SMK <kind> key=value ...` on USART2 (the ST-LINK virtual COM port, PA2/PA3, 115200 baud) and ends with `SMK done`; each plan in [plans/](plans/) waits up to 30 s for every line it waits for. The plans for `echo` also answer each `SMK ready seq=<n>` line by writing the n-th byte string listed in the plan to the board's USART2 RX (PA3), at 115200 baud, 8N1. The tests that sent the images judge the values in the serial log; the images print measurements, not verdicts.
