# hilval hq176 on a NUCLEO-F446RE

Generated by the hil-validations bench gate for one bench run; do not edit.

Two MicroPython images for the NUCLEO-F446RE, built from commit 23f0e61b47 with the same frozen `main.py`: `baseline` from the unmodified source cache (the reproduction of MicroPython #8794/#8646) and `patched` from a copy with `firmware/hq176/uart-sendbreak-docs.patch` applied, which rewrites the `UART.sendbreak()` entries of `docs/library/pyb.UART.rst` and `docs/library/machine.UART.rst`. The script sends a 0x55 and a 0x00 control frame, a break and a post-break 0x55 on a test UART that is not the REPL's (UART4 with TX on PA0, or UART3 with TX on PB10: the two this board can run at 1200 baud) at 1200, 9600 and 19200 baud in 8N1 and at 9600 baud in 8E1 and 8N2, samples that pin's own GPIO input data register by DMA2 stream 1 on TIM8 updates at 32 samples per bit and prints edge indices, the method-return marks, the SBK clear mark and DWT cycle counts; its `boot` record names the UART, the GPIO port and the pin it used, and the tests read the sample axis from that run's own registers. The tests derive the break length in bit times, place the method's return against the break's end, decode the post-break frame, and require the text the patch puts into the documents to state what the board measured. Nothing is wired to the headers: the measurement is the pin's own input register, read inside the chip.

Run by [Agentic Hardware-in-the-Loop (Agentic HIL)](https://github.com/agentic-hil/agentic-hil): its test reactor flashes each image, resets the board with the serial port open and records what the image prints; `agentic-hil run-evidence` turns each run into a report a reader without the board can check.

Each image prints lines `H176 <kind> key=value ...` on USART2 (the ST-LINK virtual COM port, PA2/PA3, 115200 baud) and ends with `H176 done`; each plan in [plans/](plans/) waits up to 180 s for every line it waits for. The tests that sent the images judge the values in the serial log; the images print measurements, not verdicts.
