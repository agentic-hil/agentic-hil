# hilval hq178 on a NUCLEO-F446RE

Generated by the hil-validations bench gate for one bench run; do not edit.

Two Embassy images for the NUCLEO-F446RE, `base` from embassy-7224/base (merge base d6825485e038f4553417c0950c15f459765d4973) and `head` from embassy-7224/head (PR #7224, 3dc12e8dd5f80d22e75124b131def830a77a43a0, `rx_data_mask()` applied in every USART reader), built from one crate under firmware/hq178/embassy. Each image exercises `blocking_read`, `UartRx::read`, `read_until_idle`, `BufferedUart` and `RingBufferedUartRx` on USART1 at 19200 baud in 7E1, 7O1, 8E1 and 8N1 with frames from the USART's half-duplex readback and with frames synthesized on the undriven RX pin by DMA2 writes to GPIOA_PUPDR on TIM8 updates, including one frame with wrong parity, 20 repetitions per configuration and reader before and again after the image's own software reset, plus a register-level control that reads USART_DR directly and stamps when PE is raised relative to RXNE. The images print raw values, results and register snapshots only; tests/hq178 computes every expectation from the sent values, the parity rule and the base or head code.

Run by [Agentic Hardware-in-the-Loop (Agentic HIL)](https://github.com/agentic-hil/agentic-hil): its test reactor flashes each image, resets the board with the serial port open and records what the image prints; `agentic-hil run-evidence` turns each run into a report a reader without the board can check.

Each image prints lines `HQ178 <kind> key=value ...` on USART2 (the ST-LINK virtual COM port, PA2/PA3, 115200 baud) and ends with `HQ178 done`; each plan in [plans/](plans/) waits up to 600 s for every line it waits for. The tests that sent the images judge the values in the serial log; the images print measurements, not verdicts.
