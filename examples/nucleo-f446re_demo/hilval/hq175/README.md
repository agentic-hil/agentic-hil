# hilval hq175 on a NUCLEO-F446RE

Generated by the hil-validations bench gate for one bench run; do not edit.

Two Embassy images for embassy-rs/embassy#3710 (enabling a timer channel's main and complementary PWM outputs independently), built from embassy revision 27d398592b8a8c415c54eb04a0893aa9ef20316d: `baseline` against the unmodified checkout and `patched` against a copy with `embassy-independent-outputs.patch` applied, which adds `set_main_output_enable`, `set_complementary_output_enable`, `get_main_output_enable` and `get_complementary_output_enable` to `ComplementaryPwm`. Both images drive TIM1 CH1 on PA8 and CH1N on PA7 (159-tick period, 40 ticks high, dead time 8 or 0 ticks) and measure both pins in-chip: DMA2 copies GPIOA_IDR on every TIM8 update (every 16 ticks, 1908 samples per measurement), the image counts high samples, both-high samples and edges and prints them with TIM1_CCER and TIM1_BDTR read back before and after every call; the pins' internal pull alternates between pull-down and pull-up per repetition so a released output shows as released. `baseline` writes the four CCER states directly at dead time 8 and 0 (`raw8`, `raw0`, the hardware controls for the RM0390 output-control table) and then today's `enable()`/`disable()` (`legacy`, which switch both outputs together). `patched` runs the four states through the new API 100 times at dead time 8 (`api8`) and 0 (`api0`), then `enable()`/`disable()` unchanged. Raw sample traces are printed for the first two repetitions (both pulls) of `raw8`, `raw0` and `api8` and the first repetition of `api0` and `legacy`, and the tests recount them. No motor, power stage, load or break input is connected; the images print measurements, the tests judge them.

Run by [Agentic Hardware-in-the-Loop (Agentic HIL)](https://github.com/agentic-hil/agentic-hil): its test reactor flashes each image, resets the board with the serial port open and records what the image prints; `agentic-hil run-evidence` turns each run into a report a reader without the board can check.
